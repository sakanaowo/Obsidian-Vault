* UnitPickerBottomSheet và CategoryPickerBottomSheet đều ép chiều cao sheet thành MATCH_PARENT trong onStart(), nên mở toàn màn hình.  
* tvConverterResult đang dùng ellipsize="start", nên khi kết quả dài Android bỏ phần đầu và giữ phần cuối.

    super.onStart();
    Dialog dialog =
            getDialog();
    if (!(dialog instanceof BottomSheetDialog)) {
        return;
    }
    BottomSheetDialog bottomSheetDialog =
            (BottomSheetDialog) dialog;
    FrameLayout sheet =
            bottomSheetDialog.findViewById(
                    com.google.android.material.R.id
                            .design_bottom_sheet
            );
    if (sheet == null) {
        return;
    }
    /*
     * Converter picker không cần chiếm toàn màn hình.
     *
     * Dùng khoảng 78% chiều cao màn hình:

     */
    int screenHeight =
            getResources()

                    .heightPixels;
    int sheetHeight =
            Math.round(
                    screenHeight * 0.78f
            );
    ViewGroup.LayoutParams layoutParams =
            sheet.getLayoutParams();
    layoutParams.height =
            sheetHeight;
    sheet.setLayoutParams(
            layoutParams
    );
    BottomSheetBehavior<FrameLayout> behavior =
            BottomSheetBehavior.from(
                    sheet
            );
    behavior.setFitToContents(
            true
    );
    behavior.setPeekHeight(
            sheetHeight
    );
    behavior.setSkipCollapsed(
            true
    );
    behavior.setState(
            BottomSheetBehavior.STATE_EXPANDED
    );
}

Polish 10.2 — Chọn Category là áp dụng ngay

Đã rà lại flow hiện tại. Có hai điểm dễ gây lỗi:

1. CategoryPickerBottomSheet chỉ gửi Fragment Result bên trong confirmSelection(). Chọn row mới chỉ thay pendingSelectedCategory, nên toàn bộ việc đổi category phụ thuộc vào nút Confirm.  
2. MainActivity bắt buộc phải đăng ký setupCategoryPickerResultListener() và handler phải gọi converterController.selectCategory(...). Thiếu một trong hai thì sheet đóng nhưng Converter không thay đổi.  

Ta polish lại thành:

Tap category
    ↓
Gửi Fragment Result ngay
    ↓
Đóng Bottom Sheet
    ↓
ConverterController.selectCategory(...)
    ↓
Đổi From / To mặc định
    ↓
Tính lại kết quả

Không còn nút Confirm.

1. Thay CategoryPickerBottomSheet.java

File:

app/src/main/java/com/example/calculator/ui/
CategoryPickerBottomSheet.java

Thay toàn bộ bằng:

package com.example.calculator.ui;
import android.app.Dialog;
import android.os.Bundle;
import android.view.LayoutInflater;
import android.view.View;
import android.view.ViewGroup;
import android.widget.FrameLayout;
import androidx.annotation.NonNull;
import androidx.annotation.Nullable;
import androidx.recyclerview.widget.LinearLayoutManager;
import androidx.recyclerview.widget.RecyclerView;
import com.example.calculator.R;
import com.example.calculator.model.UnitCategory;
import com.example.calculator.ui.adapter.CategoryAdapter;
import com.google.android.material.bottomsheet.BottomSheetBehavior;
import com.google.android.material.bottomsheet.BottomSheetDialog;
import com.google.android.material.bottomsheet.BottomSheetDialogFragment;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
/**
 * Bottom Sheet chọn conversion category.
 *
 * Interaction:
 *
 * Tap category
 *      ↓
 * Gửi Fragment Result ngay
 *      ↓
 * Đóng Bottom Sheet
 *
 * Không cần nút Confirm.
 */
public class CategoryPickerBottomSheet
        extends BottomSheetDialogFragment {
    // =========================================================
    // FRAGMENT RESULT
    // =========================================================
    public static final String RESULT_REQUEST_KEY =
            "category_picker_result";
    public static final String RESULT_CATEGORY =
            "category_picker_result_category";
    // =========================================================
    // ARGUMENT
    // =========================================================
    private static final String ARG_CURRENT_CATEGORY =
            "category_picker_current_category";
    // =========================================================
    // STATE
    // =========================================================
    private UnitCategory currentCategory;
    // =========================================================
    // UI
    // =========================================================
    private RecyclerView recyclerCategories;
    private CategoryAdapter categoryAdapter;
    // =========================================================
    // FACTORY
    // =========================================================
    public static CategoryPickerBottomSheet newInstance(
            UnitCategory currentCategory
    ) {
        CategoryPickerBottomSheet bottomSheet =
                new CategoryPickerBottomSheet();
        Bundle arguments =
                new Bundle();
        if (currentCategory != null) {
            arguments.putString(
                    ARG_CURRENT_CATEGORY,
                    currentCategory.name()
            );
        }
        bottomSheet.setArguments(
                arguments
        );
        return bottomSheet;
    }
    // =========================================================
    // LIFECYCLE
    // =========================================================
    @Override
    public void onCreate(
            @Nullable Bundle savedInstanceState
    ) {
        super.onCreate(
                savedInstanceState
        );
        readArguments();
    }
    @Nullable
    @Override
    public View onCreateView(
            @NonNull LayoutInflater inflater,
            @Nullable ViewGroup container,
            @Nullable Bundle savedInstanceState
    ) {
        return inflater.inflate(
                R.layout.bottom_sheet_category_picker,
                container,
                false
        );
    }
    @Override
    public void onViewCreated(
            @NonNull View view,
            @Nullable Bundle savedInstanceState
    ) {
        super.onViewCreated(
                view,
                savedInstanceState
        );
        bindViews(
                view
        );
        setupRecyclerView();
        setupActions(
                view
        );
        loadCategories();
    }
    /**
     * Giới hạn chiều cao để sheet không chiếm toàn màn hình.
     */
    @Override
    public void onStart() {
        super.onStart();
        Dialog dialog =
                getDialog();
        if (!(dialog instanceof BottomSheetDialog)) {
            return;
        }
        BottomSheetDialog bottomSheetDialog =
                (BottomSheetDialog) dialog;
        FrameLayout sheet =
                bottomSheetDialog.findViewById(
                        com.google.android.material.R.id
                                .design_bottom_sheet
                );
        if (sheet == null) {
            return;
        }
        int screenHeight =
                getResources()
                        .getDisplayMetrics()
                        .heightPixels;
        int sheetHeight =
                Math.round(
                        screenHeight * 0.78f
                );
        ViewGroup.LayoutParams layoutParams =
                sheet.getLayoutParams();
        layoutParams.height =
                sheetHeight;
        sheet.setLayoutParams(
                layoutParams
        );
        BottomSheetBehavior<FrameLayout> behavior =
                BottomSheetBehavior.from(
                        sheet
                );
        behavior.setFitToContents(
                true
        );
        behavior.setPeekHeight(
                sheetHeight
        );
        behavior.setSkipCollapsed(
                true
        );
        behavior.setState(
                BottomSheetBehavior.STATE_EXPANDED
        );
    }
    @Override
    public void onDestroyView() {
        super.onDestroyView();
        recyclerCategories =
                null;
        categoryAdapter =
                null;
    }
    // =========================================================
    // ARGUMENTS
    // =========================================================
    private void readArguments() {
        Bundle arguments =
                getArguments();
        if (arguments == null) {
            currentCategory =
                    UnitCategory.LENGTH;
            return;
        }
        String categoryName =
                arguments.getString(
                        ARG_CURRENT_CATEGORY
                );
        currentCategory =
                parseCategory(
                        categoryName
                );
        if (currentCategory == null) {
            currentCategory =
                    UnitCategory.LENGTH;
        }
    }
    private UnitCategory parseCategory(
            String categoryName
    ) {
        if (categoryName == null
                || categoryName.trim().isEmpty()) {
            return null;
        }
        try {
            return UnitCategory.valueOf(
                    categoryName
            );
        } catch (IllegalArgumentException exception) {
            return null;
        }
    }
    // =========================================================
    // BIND VIEWS
    // =========================================================
    private void bindViews(
            @NonNull View rootView
    ) {
        recyclerCategories =
                requireView(
                        rootView,
                        R.id.recyclerCategories
                );
    }
    private <T extends View> T requireView(
            View rootView,
            int viewId
    ) {
        T view =
                rootView.findViewById(
                        viewId
                );
        if (view == null) {
            throw new IllegalStateException(
                    "Missing Category Picker View ID: "
                            + viewId
            );
        }
        return view;
    }
    // =========================================================
    // RECYCLER VIEW
    // =========================================================
    private void setupRecyclerView() {
        recyclerCategories.setLayoutManager(
                new LinearLayoutManager(
                        requireContext()
                )
        );
        categoryAdapter =
                new CategoryAdapter(
                        this::selectCategoryImmediately
                );
        recyclerCategories.setAdapter(
                categoryAdapter
        );
    }
    // =========================================================
    // LOAD
    // =========================================================
    private void loadCategories() {
        List<UnitCategory> categories =
                new ArrayList<>();
        Collections.addAll(
                categories,
                UnitCategory.values()
        );
        categoryAdapter.setSelectedCategory(
                currentCategory
        );
        categoryAdapter.submitList(
                categories
        );
    }
    // =========================================================
    // IMMEDIATE SELECTION
    // =========================================================
    /**
     * Áp dụng category ngay khi user chạm vào row.
     */
    private void selectCategoryImmediately(
            UnitCategory category
    ) {
        if (category == null) {
            return;
        }
        Bundle result =
                new Bundle();
        result.putString(
                RESULT_CATEGORY,
                category.name()
        );
        getParentFragmentManager()
                .setFragmentResult(
                        RESULT_REQUEST_KEY,
                        result
                );
        dismiss();
    }
    // =========================================================
    // ACTIONS
    // =========================================================
    private void setupActions(
            @NonNull View rootView
    ) {
        rootView
                .findViewById(
                        R.id.btnCloseCategoryPicker
                )
                .setOnClickListener(view -> {
                    dismiss();
                });
    }
}

Thay toàn bộ method đó bằng:

private void selectCategory(
        UnitCategory category
) {
    if (category == null) {
        return;
    }
    boolean selectionChanged =
            category
                    != selectedCategory;
    selectedCategory =
            category;
    if (selectionChanged) {
        notifyDataSetChanged();
    }
    /*
     * Luôn gửi callback, kể cả khi user chạm
     * lại category hiện tại.
     *
     * Nhờ vậy:
     *
     * - chọn category mới → áp dụng và đóng;
     * - chọn lại category hiện tại → đóng sheet;
     * - không cần Confirm.
     */
    if (categorySelectedListener != null) {
        categorySelectedListener
                .onCategorySelected(
                        category
                );
    }
}

Lý do cần sửa method này:

Code cũ có:

if (category == null
        || category == selectedCategory) {
    return;
}

Do đó khi chạm category đang được check, callback không chạy và sheet không đóng.

Thiếu dòng:

Method listener phải là:

private void setupCategoryPickerResultListener() {
    getSupportFragmentManager()
            .setFragmentResultListener(
                    CategoryPickerBottomSheet
                            .RESULT_REQUEST_KEY,
                    this,
                    (requestKey, resultBundle) -> {
                        handleCategoryPickerResult(
                                resultBundle
                        );
                    }
            );
}

Handler phải kết thúc bằng:

converterController.selectCategory(
        selectedCategory
);

Method đầy đủ:

private void handleCategoryPickerResult(
        Bundle resultBundle
) {
    if (resultBundle == null
            || converterController == null) {
        return;
    }
    String categoryName =
            resultBundle.getString(
                    CategoryPickerBottomSheet
                            .RESULT_CATEGORY
            );
    if (categoryName == null
            || categoryName.trim().isEmpty()) {
        return;
    }
    UnitCategory selectedCategory;
    try {
        selectedCategory =
                UnitCategory.valueOf(
                        categoryName
                );
    } catch (IllegalArgumentException exception) {
        return;
    }
    converterController.selectCategory(
            selectedCategory
    );
}

Ngoài ra callback của ConverterController phải mở đúng Bottom Sheet:

@Override
public void onCategoryPickerRequested(
        UnitCategory currentCategory
) {
    showCategoryPickerBottomSheet(
            currentCategory
    );
}

Không được còn gọi:

showCategoryPicker(currentCategory);
