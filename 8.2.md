Tiếp tục đúng thứ tự sang Milestone M3 — Mode System, bắt đầu với Bước 8.1 — Mode State.

Theo WBS đã chốt, Mode System gồm 3 phần theo thứ tự:

8.1 Mode model/state
        ↓
8.2 Mode popup
        ↓
8.3 Mode switching

Ba mode của app là:

BASIC
SCIENTIFIC
CONVERT

và việc đổi mode phải diễn ra trong cùng MainActivity, không restart Activity.   Thiết kế UI cũng đã chốt btnMode mở menu gồm Basic / Scientific / Convert, với mode hiện tại có dấu chọn.  

Ở bước này chỉ thiết lập state quản lý mode.

Chưa tạo popup.

Chưa dựng Scientific UI thật.

Chưa dựng Converter UI thật.

Bước 8.1 — Mode State

Ta đã tạo enum từ Project Skeleton:

app/src/main/java/com/example/calculator/engine/CalculatorMode.java

Nội dung phải là:

package com.example.calculator.engine;
public enum CalculatorMode {
    BASIC,
    SCIENTIFIC,
    CONVERT
}

Nếu file hiện tại đã đúng như trên thì không sửa.

8.1.2 — Thêm field currentMode

Trong MainActivity, gần các field hiện tại:

private CalculatorEngine calculatorEngine;
private HistoryManager historyManager;

thêm:

private CalculatorMode currentMode;

Thành:

private CalculatorEngine calculatorEngine;
private HistoryManager historyManager;
private CalculatorMode currentMode;
private TextView tvExpression;
private TextView tvResult;

State này sẽ là nguồn duy nhất cho mode hiện tại:

currentMode
    │
    ├── BASIC
    ├── SCIENTIFIC
    └── CONVERT

Không tạo thêm:

boolean isScientific;
boolean isConverter;

vì dễ sinh trạng thái mâu thuẫn kiểu:

isScientific = true
isConverter  = true

Enum loại bỏ vấn đề đó.

8.1.4 — Tạo helper setCalculatorMode()

Thêm method vào MainActivity:

// =========================================================
// CALCULATOR MODE
// =========================================================
/**
 * Thay đổi mode hiện tại của calculator.
 *
 * Ở bước 8.1 method này mới chỉ quản lý state.
 *
 * UI switching sẽ được bổ sung ở bước 8.3.
 */
private void setCalculatorMode(
        CalculatorMode mode
) {
    if (mode == null) {
        return;
    }
    /*
     * Không làm gì nếu chọn lại mode hiện tại.
     */
    if (currentMode == mode) {
        return;
    }
    currentMode =
            mode;
    /*
     * Bước 8.3 sẽ gọi:
     *
     * renderCalculatorMode();
     *
     * tại đây.
     */
}

Hiện tại method chưa được gọi vì popup chưa tồn tại.

Đây là chủ ý.

⸻

8.1.5 — Tạo helper kiểm tra mode

Thêm tiếp:

private boolean isCurrentMode(
        CalculatorMode mode
) {
    return currentMode == mode;
}

Sau này popup dùng:

isCurrentMode(
        CalculatorMode.BASIC
)

để quyết định:

✓ Basic

hoặc:

Basic

Tương tự:

isCurrentMode(
        CalculatorMode.SCIENTIFIC
);

và:

isCurrentMode(
        CalculatorMode.CONVERT
);

8.1.8 — Không reset Calculator khi đổi mode

Sau này khi gọi:

setCalculatorMode(
        CalculatorMode.SCIENTIFIC
);

không nên tự động làm:

calculatorEngine.clear();

trong setCalculatorMode().

Lý do:

Basic:
25 × 4
100
        ↓ đổi mode
Scientific:
vẫn có thể tiếp tục dùng 100

Việc chia sẻ hay reset display giữa từng mode sẽ được quyết định cụ thể khi tích hợp Scientific/Converter.

Mode state và calculator state là hai thứ khác nhau:

CalculatorMode
│
├── BASIC
├── SCIENTIFIC
└── CONVERT
CalculatorState
│
├── currentInput
├── expression
├── result
├── operator
└── ...

Không trộn hai state này.

8.1.9 — Phần liên quan trong MainActivity

Sau khi cập nhật, đầu class sẽ gần giống:

public class MainActivity
        extends AppCompatActivity {
    private static final String
            TAG_HISTORY_BOTTOM_SHEET =
            "HistoryBottomSheet";
    private CalculatorEngine
            calculatorEngine;
    private HistoryManager
            historyManager;
    /*
     * Mode hiện tại của ứng dụng.
     */
    private CalculatorMode
            currentMode;
    private TextView
            tvExpression;
    private TextView
            tvResult;
    @Override
    protected void onCreate(
            Bundle savedInstanceState
    ) {
        super.onCreate(
                savedInstanceState
        );
        EdgeToEdge.enable(this);
        setContentView(
                R.layout.activity_main
        );
        setupSystemBars();
        calculatorEngine =
                new CalculatorEngine();
        historyManager =
                new HistoryManager(
                        getApplicationContext()
                );
        currentMode =
                CalculatorMode.BASIC;
        bindViews();
        setupDigitButtons();
        setupOperatorButtons();
        setupFunctionButtons();
        setupHistoryButton();
        renderState();
    }
    // ...
}

Và thêm:

private void setCalculatorMode(
        CalculatorMode mode
) {
    if (mode == null) {
        return;
    }
    if (currentMode == mode) {
        return;
    }
    currentMode =
            mode;
}
private boolean isCurrentMode(
        CalculatorMode mode
) {
    return currentMode == mode;
}
