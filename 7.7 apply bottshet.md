Tiếp tục đúng thứ tự sang Bước 7.7 — triển khai HistoryBottomSheet.java.

Ở bước trước, bottom_sheet_history.xml đã có đủ RecyclerView, empty state, nút đóng và vùng Clear. Bây giờ ta nối các thành phần bên trong sheet với HistoryManager và HistoryAdapter. History vẫn được thiết kế dưới dạng BottomSheetDialogFragment, dữ liệu lấy từ local storage khi sheet mở.  

Luồng sau bước này:

HistoryBottomSheet mở
        ↓
HistoryManager.getAll()
        ↓
List<HistoryItem>
        ↓
HistoryAdapter
        ↓
RecyclerView
Nếu list rỗng
        ↓
"No calculations yet"

Chưa nối btnHistory trong MainActivity.
Chưa implement Delete/Clear thật sự.

Bước 7.7 — Implement HistoryBottomSheet.java

File:

app/src/main/java/com/example/calculator/ui/HistoryBottomSheet.java

Thay toàn bộ nội dung bằng:

package com.example.calculator.ui;
import android.os.Bundle;
import android.view.LayoutInflater;
import android.view.View;
import android.view.ViewGroup;
import android.widget.TextView;
import androidx.annotation.NonNull;
import androidx.annotation.Nullable;
import androidx.recyclerview.widget.LinearLayoutManager;
import androidx.recyclerview.widget.RecyclerView;
import com.example.calculator.R;
import com.example.calculator.history.HistoryManager;
import com.example.calculator.model.HistoryItem;
import com.example.calculator.ui.adapter.HistoryAdapter;
import com.google.android.material.bottomsheet.BottomSheetDialogFragment;
import java.util.List;
/**
 * Bottom Sheet hiển thị Calculation History.
 *
 * Trách nhiệm:
 *
 * - Inflate bottom_sheet_history.xml
 * - Load history từ HistoryManager
 * - Hiển thị bằng HistoryAdapter
 * - Quản lý empty state
 * - Đóng Bottom Sheet
 *
 * Chưa xử lý ở bước này:
 *
 * - Delete một item
 * - Clear toàn bộ history
 */
public class HistoryBottomSheet
        extends BottomSheetDialogFragment {
    // =========================================================
    // DATA
    // =========================================================
    private HistoryManager historyManager;
    private HistoryAdapter historyAdapter;
    // =========================================================
    // VIEW
    // =========================================================
    private RecyclerView recyclerHistory;
    private TextView tvEmptyHistory;
    private TextView btnClearHistory;
    // =========================================================
    // CREATE VIEW
    // =========================================================
    @Nullable
    @Override
    public View onCreateView(
            @NonNull LayoutInflater inflater,
            @Nullable ViewGroup container,
            @Nullable Bundle savedInstanceState
    ) {
        return inflater.inflate(
                R.layout.bottom_sheet_history,
                container,
                false
        );
    }
    // =========================================================
    // VIEW CREATED
    // =========================================================
    @Override
    public void onViewCreated(
            @NonNull View view,
            @Nullable Bundle savedInstanceState
    ) {
        super.onViewCreated(
                view,
                savedInstanceState
        );
        /*
         * Local persistence manager.
         */
        historyManager =
                new HistoryManager(
                        requireContext()
                                .getApplicationContext()
                );
        /*
         * Bind XML views.
         */
        bindViews(view);
        /*
         * Setup RecyclerView.
         */
        setupRecyclerView();
        /*
         * Close button.
         */
        setupCloseButton(view);
        /*
         * Load dữ liệu hiện có.
         */
        loadHistory();
    }
    // =========================================================
    // BIND VIEWS
    // =========================================================
    private void bindViews(
            @NonNull View rootView
    ) {
        recyclerHistory =
                rootView.findViewById(
                        R.id.recyclerHistory
                );
        tvEmptyHistory =
                rootView.findViewById(
                        R.id.tvEmptyHistory
                );
        btnClearHistory =
                rootView.findViewById(
                        R.id.btnClearHistory
                );
    }
    // =========================================================
    // RECYCLER VIEW
    // =========================================================
    private void setupRecyclerView() {
        /*
         * History hiển thị dạng list dọc:
         *
         * newest
         * ↓
         * oldest
         */
        recyclerHistory.setLayoutManager(
                new LinearLayoutManager(
                        requireContext()
                )
        );
        /*
         * Ở bước 7.7 chưa xử lý delete,
         * nên callback long-click = null.
         *
         * Bước 7.9 sẽ thay null bằng callback thật.
         */
        historyAdapter =
                new HistoryAdapter(
                        null,
                        null
                );
        recyclerHistory.setAdapter(
                historyAdapter
        );
    }
    // =========================================================
    // CLOSE
    // =========================================================
    private void setupCloseButton(
            @NonNull View rootView
    ) {
        rootView
                .findViewById(
                        R.id.btnCloseHistory
                )
                .setOnClickListener(view -> {
                    dismiss();
                });
    }
    // =========================================================
    // LOAD HISTORY
    // =========================================================
    /**
     * Load dữ liệu từ SharedPreferences
     * thông qua HistoryManager.
     */
    private void loadHistory() {
        List<HistoryItem> history =
                historyManager.getAll();
        /*
         * Cập nhật RecyclerView.
         */
        historyAdapter.submitList(
                history
        );
        /*
         * Render state:
         *
         * HAS_DATA
         *
         * hoặc
         *
         * EMPTY
         */
        renderHistoryState(
                history
        );
    }
    // =========================================================
    // STATE
    // =========================================================
    private void renderHistoryState(
            List<HistoryItem> history
    ) {
        boolean isEmpty =
                history == null
                        || history.isEmpty();
        if (isEmpty) {
            /*
             * Không có calculation.
             */
            recyclerHistory.setVisibility(
                    View.GONE
            );
            tvEmptyHistory.setVisibility(
                    View.VISIBLE
            );
            btnClearHistory.setVisibility(
                    View.GONE
            );
        } else {
            /*
             * Có calculation history.
             */
            recyclerHistory.setVisibility(
                    View.VISIBLE
            );
            tvEmptyHistory.setVisibility(
                    View.GONE
            );
            /*
             * Hiện nút Clear khi có dữ liệu.
             *
             * Action của Clear sẽ implement
             * riêng ở bước 7.9.
             */
            btnClearHistory.setVisibility(
                    View.VISIBLE
            );
        }
    }
}

7.7.2 — Flow khi đã có History

Giả sử trước đó đã tính:

25 × 4 = 100
20 ÷ 5 = 4

SharedPreferences đang có hai item.

Khi sheet mở:

historyManager.getAll();

trả về:

[
    20 ÷ 5 → 4,
    25 × 4 → 100
]

Sau đó:

historyAdapter.submitList(history);

RecyclerView hiển thị:

╭────────────────────────────────────╮
│                ━                   │
│ Clear        History          ✕    │
├────────────────────────────────────┤
│                           20 ÷ 5   │
│                                 4  │
├────────────────────────────────────┤
│                           25 × 4   │
│                               100  │
╰────────────────────────────────────╯

Item mới nhất ở trên vì HistoryManager.add() đã lưu theo thứ tự mới → cũ.

7.7.4 — Vì sao tạo HistoryManager riêng trong Bottom Sheet?

        ↓

             │
             └──── same SharedPreferences

Không tạo database mới.

Không tạo history riêng.
