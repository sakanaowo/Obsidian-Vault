# **B** Là Gì?

**B** = **Batch size** = số hình ảnh xử lý cùng lúc

Ví dụ: `(B=32, c1, H, W)` = xử lý 32 ảnh cùng lúc, mỗi ảnh có `c1` channels, kích thước `H×W` pixels.

---

# Tổng Hợp: Inception Block Forward

## 1️⃣ **Inception Block Là Gì?**

4 nhánh song song nhìn input ở **4 độ zoom khác nhau** → gộp lại:

```
Input (B, C_in, H, W)
├─ Branch 1: 1×1 Conv → c1 channels
├─ Branch 2: 1×1 Conv → 3×3 Conv → c2[1] channels  (hạ chiều trước để tiết kiệm)
├─ Branch 3: 1×1 Conv → 5×5 Conv → c3[1] channels  (hạ chiều trước)
└─ Branch 4: MaxPool → 1×1 Conv → c4 channels
                    ↓
        Output (B, c1+c2[1]+c3[1]+c4, H, W)
```

**Tại sao?** Mỗi kernel size nắm bắt đặc trưng ở tỷ lệ khác nhau → học đầy đủ hơn.

---

## 2️⃣ **Tại Sao Không Dùng `nn.ReLU()`?**

| | `nn.ReLU()` | `F.relu()` |
|---|---|---|
| **Kiểu** | Layer (chiếm bộ nhớ) | Hàm (không chiếm) |
| **Nếu dùng 8 lần** | Phải tạo 8 layers | Gọi trực tiếp 8 lần |
| **Khi** | Có tham số học tập | Không có tham số |

**Inception dùng `F.relu()`** vì ReLU không có tham số, gọi 8 lần nên dùng hàm tiết kiệm.

---

## 3️⃣ **Công Thức ReLU**

$$\text{ReLU}(x) = \max(0, x) = \begin{cases} x & \text{if } x > 0 \\ 0 & \text{otherwise} \end{cases}$$

**Trong forward:**
```python
b1 = F.relu(self.b1_1(x))  
# Conv(1×1) output → ReLU "kích hoạt" (giữ dương) hoặc "tắt" (set=0)

b2 = F.relu(self.b2_2(F.relu(self.b2_1(x))))
# Conv(1×1) → ReLU → Conv(3×3) → ReLU
# Mỗi ReLU xoá những giá trị âm
```

**Tại sao ReLU sau Conv?**
- Conv output có thể âm/dương
- ReLU quyết định neuron "bật" hay "tắt"
- **Không ReLU** = n layers Conv chỉ = 1 layer (toán tuyến tính)

---

## 4️⃣ **Output Shapes**

```
Input: (B=32, 192, 28, 28)  ← B=batch_size=32

b1: (32, c1, 28, 28)          ← 32 ảnh, c1 channels
b2: (32, c2[1], 28, 28)       ← 32 ảnh, c2[1] channels
b3: (32, c3[1], 28, 28)       ← 32 ảnh, c3[1] channels
b4: (32, c4, 28, 28)          ← 32 ảnh, c4 channels

Output: (32, c1+c2[1]+c3[1]+c4, 28, 28)  ← Gộp 4 nhánh vào chiều channels
```

> [!NOTE] 
> body không có nghĩa là giữ nguyên kích thước mãi; body thường gồm nhiều stage, và mỗi stage thường có một bước downsample (stride=2/pool) để đổi từ “chi tiết cao” sang “ngữ nghĩa cao”.
