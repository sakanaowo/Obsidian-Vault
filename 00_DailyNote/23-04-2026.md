## Unidirectional vs Bidirectional RNN

### Định nghĩa

- **Unidirectional**: Xử lý chuỗi theo **1 hướng** (trái → phải). Hidden state tại $t$ chỉ phụ thuộc vào quá khứ ($x_t, h_{t-1}$), không có thông tin từ tương lai.
- **Bidirectional**: Xử lý theo **2 hướng đồng thời** (forward + backward). Hidden state kết hợp: $h_t = [\overrightarrow{h_t}; \overleftarrow{h_t}]$ → biết toàn bộ chuỗi.

### Mặc định vs Đặc biệt

- **Unidirectional = Mặc định** (90% trường hợp) — tự nhiên, nhanh, dùng cho synthesis/generation
- **Bidirectional = Đặc biệt** (10% trường hợp) — khi cần full context, chấp nhận latency cao

### Khi nào dùng?

**Unidirectional**

- Language Model (GPT): sinh từ tiếp theo
- Seq2Seq Decoder: sinh token autoregressively
- Time Series Prediction: dự đoán tương lai từ quá khứ
- Speech Recognition (streaming): realtime latency thấp
- Bất kỳ task nào cần sinh output

**Bidirectional:**

- Seq2Seq Encoder: mã hóa toàn bộ câu nguồn
- NER/POS Tagging: cần context cả trước lẫn sau để phân loại từ
- Sentiment Analysis: "not → bad" (cần xem "not" để hiểu sentiment)
- Text Classification: phân loại toàn văn bản
- BERT, ELMo: pre-training models để học representation mạnh

**Không dùng Bidirectional cho Decoder**: vô lý — "nhìn tương lai" của output chưa sinh = information leakage

### Ví dụ: POS Tagging "Bank"

|            | Unidirectional              | Bidirectional                   |
| ---------- | --------------------------- | ------------------------------- |
| Context    | Chỉ "Bank"                  | "Bank deposit is safe"          |
| Quyết định | ⚠️ Ambiguous (ORG or NOUN?) | ✅ Rõ ràng (NOUN: account type) |
| Accuracy   | ~92%                        | ~96%                            |

### Công thức

- Unidirectional GRU: $h_t = \text{GRU}(x_t, h_{t-1})$
- Bidirectional GRU: $h_t = [\text{GRU}_{\text{fwd}}(x_t, h_{t-1}); \text{GRU}_{\text{bwd}}(x_t, h_{t+1})]$

### Quy tắc vàng

```
Sinh output (LM, Decoder, TS) → Unidirectional (chỉ xem quá khứ)
Phân loại/Hiểu ngữ cảnh → Bidirectional (xem toàn cảnh)
Latency quan trọng → Unidirectional
Full sequence sẵn có → Có thể dùng Bidirectional
```
